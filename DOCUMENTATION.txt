# Менеджер сертификатов V1.0 — Техническая документация

ОБЯЗАТЕЛЬНО ВНЕСИТЕ СОЗДАННУЮ ПАПКУ "C:\CM" В ИСКЛЮЧЕНИЯ ВАШЕГО АНТИВИРУСА!!!

## 1. Общее описание

Менеджер сертификатов V1.0 — комплекс PowerShell-скриптов для автоматизации 
управления сертификатами и криптографическими компонентами в инфраструктуре 
Республики Беларусь.

**Основные задачи:**
- Обновление сертификатов и списков отзыва (CRL)
- Установка компонентов Авест (криптопровайдеры, комплекты абонента)
- Установка плагина AvCMXWebP для работы порталов в IE Mode
- Настройка автозапуска через планировщик Windows
- Мониторинг и логирование всех операций
- Управление политикой выполнения PowerShell скриптов

## 3. Описание скриптов

### 3.1. CertificateManagerV1.ps1 — GUI

Графический интерфейс на Windows Forms. При запуске сворачивает консоль.
Путь деплоя: `C:\CM`

Кнопки разделены на две колонки:
- **Левая (синие):** Обновить сертификаты, Установить компоненты Авест,
  Установить плагин AvCMXWebP, Запланировать автозапуск
- **Правая (светлые):** URL сертификатов, Инфо о компонентах,
  Информация о плагине, Открыть папку, Выход

Блокировка повторных нажатий, цветовая индикация статуса.

**Переменные блокировки:** `$schedulerRunning`, `$updateRunning`, `$installRunning`, 
`$folderWindowOpen`, `$urlFileOpen`, `$avestInstallRunning`

### 3.2. Common-FunctionsV1.ps1 — Общий модуль

**Логирование:** 
- `Write-Log`, `Write-ExitLog`
- Глобальные переменные `$script:NormalExit`, `$script:LogPath`
- Обработчик `PowerShell.Exiting`, перехват `trap`

**Сетевые функции:** 
- `Test-InternetConnection` (DNS + TCP + ping)
- `Save-FileWithFallback` (скачивание через WebRequest с резервными URL)

**Архивы:** 
- `Get-WinRARPath` (поиск WinRAR)
- `Expand-Archive` (ZIP через встроенный командлет, RAR через WinRAR)

**Конфигурация:** 
- `Import-Config` (INI → хеш-таблица)

**Подтверждение:** 
- `Confirm-Action` (д/н)

**Проверка компонентов Авест (по реестру):** 
- `Test-AvPass`, `Test-AvBign`, `Test-AvCSPBel`, `Test-AvCSPBign`, `Test-AvReg`

### 3.3. Update-OnlyCertificatesV1.ps1

Скачивание и установка сертификатов/CRL без установки компонентов Авест.
Параметр `-ResultFile`. Коды возврата: 0 — успех, 1 — ошибка.
При отсутствии прав администратора перезапускается с ними.

### 3.4. Update-CertificatesV1_Core.ps1 — Ядро обновления

**Алгоритм:**
1. Создание папок `logs`, `downloads`, временной папки в `%TEMP%`
2. Поиск `AvCmUt4.exe` и `MngCert.exe` в `C:\Program Files\Avest\AvPCM*\`
3. Чтение `all_certs_urls.txt` (пропуск пустых строк и строк с `#`)
4. Скачивание файлов во временную папку (WebRequest)
5. Копирование скачанных файлов в папку `downloads`
6. Закрытие блокирующих процессов (AvPCM, MngCert, mmc, certmgr)
7. Импорт в хранилища Windows:
   - `.cer` → Root (если имя содержит root/kuc/mns_root) или CA
   - `.crl` → через AvCmUt4.exe (или certutil)
   - `.p7b` → certutil -addstore CA
8. Сохранение результата в JSON (при указании `-ResultFile`)
9. Очистка временных файлов, удаление `AvCmUt4.log`

**Приоритет импорта сертификатов:** MngCert.exe → certutil → .NET fallback (для NTE_BAD_KEYSET)

### 3.5. Install-AvestComponentsV1.ps1

Интерактивная установка компонентов. Параметр `-ScriptPath`.

**Алгоритм:**
1. Загрузка конфигурации из `config\avest_urls.ini`
2. Вывод меню выбора (1-5, 0 — выход)
3. Для выбранного компонента:
   - Очистка `avest\unpacked\`
   - Скачивание ZIP-архива (с резервными URL)
   - Распаковка через `Expand-Archive`
   - Поиск установщика:
     - AvPass: `AvPKISetup(bel)\AvPKISetup2.exe`
     - AvBign: `AvPKISetup(bign)\AvPKISetup2.exe`
     - AvCSPBel: `AvPKISetup(bel)\data\setupAvCSPBel*.exe`
     - AvCSPBign: `AvPKISetup(bign)\data\setupAvCSPBign*.exe`
     - AvReg: `requireSAI_DLL.reg`
   - Запуск установки (для `.reg` — `reg import`)
4. Повтор до выбора 0

### 3.6. Install-AvCMXWebPV1.ps1

Автоматическая установка плагина. Параметры: `-ScriptPath`, `-LogsFolder`.

**Алгоритм:**
1. Проверка, установлен ли плагин (реестр + файлы)
2. Если установлен — запрос на переустановку
3. Очистка `avest\unpacked\`
4. Скачивание `AvPKISetup(bel).zip`
5. Распаковка архива
6. Поиск `AvCMXWebP-*.exe` в `AvPKISetup(bel)\data\`
7. Выбор самого свежего (по дате изменения)
8. Запуск установщика

**Поддерживаемые URL (с резервными):**
- `https://nces.by/wp-content/uploads/gossuok/AvPKISetup(bel).zip`
- `https://goszakupki.by/upload/AvPKISetup(bel).zip`
- `https://portal.nalog.gov.by/ca/AvPKISetup(bel).zip`

### 3.7. Create-ScheduledTaskV1.ps1

Создание задачи в планировщике Windows.

**Параметры задачи:**
- Имя: `Update-OnlyCertificates`
- Триггер: при старте системы
- Задержка: 2 минуты
- Пользователь: SYSTEM
- Права: HIGHEST

**Алгоритм:**
1. Проверка наличия `Update-OnlyCertificatesV1.ps1`
2. Запрос подтверждения у пользователя
3. Удаление старой задачи (если существует)
4. Создание временного скрипта-обёртки в `%TEMP%` с проверкой интернета
5. Создание задачи через `schtasks`
6. Запуск задачи для проверки

**Проверка интернета в обёртке:**
- Проверка доступности сайтов (goszakupki.by, nces.by, portal.nalog.gov.by, 1.1.1.1)
- До 10 попыток (5 минут) с интервалом 30 секунд
- Лог обёртки: `C:\CM\logs\autostart_*.log`

### 3.8. enable_scriptsV1.ps1 — Разрешение выполнения скриптов

Устанавливает политику выполнения `Unrestricted`, которая разрешает запуск 
любых PowerShell скриптов (локальных и удалённых).

**Алгоритм:**
1. Запрос прав администратора
2. Разблокировка всех `.ps1` файлов в `C:\CM` (`Unblock-File`)
3. Проверка текущей политики
4. Установка `Unrestricted` через `Set-ExecutionPolicy`
5. Вывод результата

**Ручная команда:** `Set-ExecutionPolicy Unrestricted -Force`

### 3.9. disable_scriptsV1.ps1 — Запрет выполнения скриптов

Устанавливает политику выполнения `Restricted`, которая полностью запрещает 
запуск любых PowerShell скриптов.

**Алгоритм:**
1. Запрос прав администратора
2. Предупреждение и подтверждение
3. Проверка текущей политики
4. Установка `Restricted` через `Set-ExecutionPolicy`
5. Вывод результата

**Ручная команда:** `Set-ExecutionPolicy Restricted -Force`

## 5. Конфигурационные файлы

Список URL для скачивания сертификатов и CRL.
- Пустые строки и строки, начинающиеся с `#`, игнорируются
- Поддерживаются файлы: `.cer`, `.crl`, `.p7b`

**Содержит ссылки на источники:**

## 6. Политики выполнения PowerShell

================================================================================
  ПОЛИТИКИ ВЫПОЛНЕНИЯ POWERSHELL
================================================================================
  Restricted    -  Полное отключение (сценарии НЕ выполняются)
  Unrestricted  -  Всё выполняется (требуется подтверждение для удалённых)
  RemoteSigned  -  Локальные выполняются, удалённые только подписанные
  Bypass        -  Всё выполняется, ничего не блокируется
  AllSigned     -  Только подписанные сценарии
================================================================================

**Важно:** Задача в планировщике и GUI используют `-ExecutionPolicy Bypass`, 
поэтому они работают даже при политике `Restricted`.

## 7. Обработка ошибок и логирование

**Типы логов (папка `C:\CM\logs\`):**
- `import_*.log` — обновление сертификатов
- `avest_install_*.log` — установка компонентов Авест
- `avcmxwebp_install_*.log` — установка плагина
- `autostart_*.log` — автозапуск (обёртка планировщика)

**Глобальный обработчик:** 
- `Register-EngineEvent` для корректного выхода при закрытии окна
- `trap` для перехвата ошибок и записи в лог

**Коды возврата:** 
- `0` — успех
- `1` — ошибка

================================================================================
  ТИПИЧНЫЕ ОШИБКИ И ИХ ОБРАБОТКА
================================================================================
  NTE_BAD_KEYSET (0x80090016)  - .NET fallback
  already exists               - INFO, не считается ошибкой
  WinRAR не найден             - Инструкция по установке WinRAR
  Нет интернета                - Инструкция по ручной установке
  Недостаточно прав            - Автоматический запрос прав
================================================================================

## 9. Руководство по эксплуатации

**Запуск:** Ярлык на рабочем столе или `C:\CM\CertificateManagerV1.ps1`

**Обновление сертификатов:** Нажмите кнопку "Обновить сертификаты"

**Установка компонентов Авест:** 
1. Нажмите "Установить компоненты Авест"
2. Выберите номер компонента (1-5)
3. Подтвердите установку (д/н)
4. Следуйте инструкциям мастера

**Установка плагина:** Нажмите "Установить плагин AvCMXWebP"

**Настройка автозапуска:** Нажмите "Запланировать автозапуск"

**Просмотр информации:** 
- "Инфо о компонентах" — статус установки компонентов Авест
- "Информация о плагине" — версия плагина

**Редактирование URL:** Нажмите "URL сертификатов" (откроется Блокнот)

**Открытие папки:** Нажмите "Открыть папку"

**Управление политикой выполнения:**
- Разрешить скрипты: `.\enable_scriptsV1.ps1`
- Запретить скрипты: `.\disable_scriptsV1.ps1`

## 10. Устранение неполадок

================================================================================
  УСТРАНЕНИЕ НЕПОЛАДОК
================================================================================
  Проблема                                 Решение
  ----------------------------------------------------------------------------
  Ошибка "Не удается загрузить файл"       Запустите enable_scriptsV1.ps1
  Окно закрывается сразу                   Запустите от имени администратора
  Крякозябры вместо русского               Сохраните скрипты в "UTF-8 со спецификацией"
  Ошибка скачивания                        Проверьте интернет и доступность сайтов
  Не найден MngCert.exe / AvCmUt4.exe      Установите компоненты Авест
  Антивирус блокирует                      Добавьте C:\CM в исключения
  Задача не создаётся                      Запустите от администратора
  Скрипт не запускается при старте         Проверьте лог autostart_*.log
================================================================================

**Диагностические команды:**
powershell
# Просмотр ошибок в логах
Get-Content "C:\CM\logs\import_*.log" | Select-String "ОШИБКА"

# Последние 50 строк лога
Get-Content "C:\CM\logs\import_*.log" -Tail 50

# Текущая политика выполнения
Get-ExecutionPolicy

# Проверка задачи в планировщике
schtasks /query /tn Update-OnlyCertificates

# Запуск задачи вручную
schtasks /run /tn Update-OnlyCertificates

# Удаление задачи
schtasks /delete /tn Update-OnlyCertificates /f

## 11. Расширение и модификация

**Добавление источников сертификатов:** 
Отредактируйте `all_certs_urls.txt` (новая ссылка с новой строки)

**Добавление компонента Авест:**
1. Добавьте секцию в `config\avest_urls.ini`
2. Добавьте функцию `Test-NewComponent` в `Common-FunctionsV1.ps1`
3. Добавьте компонент в массив `$components` в `Install-AvestComponentsV1.ps1`
4. Добавьте путь поиска в функцию `Find-Installer`

**Изменение расписания автозапуска:** 
В `Create-ScheduledTaskV1.ps1` измените параметр `/delay` (задержка) или `/sc` (триггер)

**Изменение папки деплоя:** 
Замените `C:\CM` на нужный путь во всех скриптах и комментариях

# 📘 Менеджер сертификатов V2.0 — Техническая документация

## 1. Общее описание

Менеджер сертификатов V2.0 — комплекс PowerShell-скриптов для автоматизации 
управления сертификатами и криптографическими компонентами в инфраструктуре

- Настройка автозапуска через планировщик Windows
- Мониторинг и логирование всех операций
- Управление политикой выполнения PowerShell скриптов

## 3. Описание скриптов

### 3.1. CertificateManagerV2.ps1 — GUI

Графический интерфейс на Windows Forms. При запуске сворачивает консоль. 
Кнопки разделены на две колонки: основные операции (синие) и вспомогательные (светлые). 
Блокировка повторных нажатий, цветовая индикация статуса.

**Переменные блокировки:** `$schedulerRunning`, `$updateRunning`, `$installRunning`, 
`$folderWindowOpen`, `$urlFileOpen`, `$avestInstallRunning`

### 3.2. Common-Functions.ps1 — Общий модуль (v2.1)

**Логирование:** 
- `Write-Log`, `Write-ExitLog`
- Глобальные переменные `$script:NormalExit`, `$script:LogPath`
- Обработчик `PowerShell.Exiting`, перехват `trap`

**Сетевые функции:** 
- `Test-InternetConnection` (DNS + TCP + ping)
- `Save-FileWithFallback` (скачивание с резервными URL, ВСЕГДА перезапись)

**Архивы:** 
- `Get-WinRARPath` (поиск WinRAR)
- `Expand-Archive` (ZIP через встроенный командлет, RAR через WinRAR)

**Конфигурация:** 
- `Import-Config` (INI → хеш-таблица)

**Подтверждение:** 
- `Confirm-Action` (д/н)

**Проверка компонентов Авест:** 
- `Test-AvPass`, `Test-AvBign`, `Test-AvCSPBel`, `Test-AvCSPBign`, `Test-AvReg`

### 3.3. Update-OnlyCertificates.ps1

Скачивание и установка сертификатов/CRL без компонентов Авест. 
Параметр `-ResultFile`. Коды возврата: 0 — успех, 1 — ошибка.

### 3.4. Update-CertificatesV2_Core.ps1 — Ядро

- Создание папок `logs`, `downloads`, временной папки
- Поиск `AvCmUt4.exe` и `MngCert.exe` в `Program Files\Avest\`
- Чтение `all_certs_urls.txt` (пропуск пустых строк и `#`)
- Скачивание файлов во временную папку
- Импорт: `.cer` → Root/CA (приоритет: MngCert.exe → certutil → .NET fallback), 
  `.crl` → AvCmUt4.exe → certutil, `.p7b` → certutil
- Сохранение копий в `downloads`
- Вывод результата в JSON при указании `-ResultFile`
- Очистка временных файлов, удаление `AvCmUt4.log`

### 3.5. Install-AvestComponents.ps1 (v2.1)

Интерактивная установка компонентов. Параметр `-ScriptPath`.

**Алгоритм:**
1. Проверка статуса компонентов
2. Вывод цветной таблицы
3. Предупреждение об антивирусе
4. Меню выбора (1-5, 0 — выход)
5. Для выбранного компонента:
   - Очистка `unpacked`
   - Скачивание архива (всегда, удаляя старый)
   - Распаковка через `Microsoft.PowerShell.Archive\Expand-Archive`
   - Поиск установщика по фиксированным путям:
     - AvPass: `AvPKISetup(bel)\AvPKISetup2.exe`
     - AvBign: `AvPKISetup(bign)\AvPKISetup2.exe`
     - AvCSPBel: `AvPKISetup(bel)\data\setupAvCSPBel*.exe` → `setupAvCSPBel*.exe`
     - AvCSPBign: `AvPKISetup(bign)\data\setupAvCSPBign*.exe` → `setupAvCSPBign*.exe`
     - AvReg: `requireSAI_DLL.reg`
   - Запуск установщика (regedit /s для реестра)
6. Повтор до выбора 0

### 3.6. Install-AvCMXWebP.ps1 (v2.1)

Автоматическая установка плагина. Параметры: `-ScriptPath`, `-LogsFolder`.

**Алгоритм:**
1. Очистка `unpacked`
2. Скачивание `AvPKISetup(bel).zip` (всегда, удаляя старый)
3. Распаковка архива
4. Поиск плагина в:
   - `AvPKISetup(bel)\data\AvCMXWebP-*.exe`
   - `AvPKISetup(bign)\data\AvCMXWebP-*.exe`
5. Выбор самого свежего (по дате)
6. Запуск установки

**Поддерживаемые URL (с резервными):**
- `https://nces.by/wp-content/uploads/gossuok/AvPKISetup(bel).zip`
- `https://goszakupki.by/upload/AvPKISetup(bel).zip`
- `https://portal.nalog.gov.by/ca/AvPKISetup(bel).zip`

### 3.7. Create-ScheduledTaskV2.ps1

Создание задачи в планировщике:
- Имя: `Update-OnlyCertificates`
- Триггер: при старте системы
- Задержка: 2 минуты
- Пользователь: SYSTEM
- Права: HIGHEST

Создаётся временный скрипт-обёртка с проверкой интернета (до 10 попыток, 5 минут), 
который запускает `Update-OnlyCertificates.ps1`.

### 3.8. enable_scripts.ps1 — Разрешение выполнения скриптов

Устанавливает политику выполнения `RemoteSigned`, которая позволяет запускать 
локальные скрипты без подписи, а удалённые — только с цифровой подписью.

**Алгоритм:**
1. Запрос прав администратора
2. Разблокировка всех `.ps1` файлов в текущей папке (`Unblock-File`)
3. Проверка текущей политики:
   - Если `RemoteSigned` — сообщает, что уже настроено
   - Если `Bypass` — сообщает, что всё разрешено (опционально установка)
   - Иначе — установка `RemoteSigned` через реестр или `Set-ExecutionPolicy`
4. Вывод результата

**Ручная команда:** `Set-ExecutionPolicy RemoteSigned -Force`

### 3.9. disable_scripts.ps1 — Запрет выполнения скриптов

Устанавливает политику выполнения `Restricted`, которая полностью запрещает 
запуск любых PowerShell скриптов.

**Алгоритм:**
1. Запрос прав администратора
2. Предупреждение и подтверждение
3. Проверка текущей политики
4. Установка `Restricted` через `Set-ExecutionPolicy`
5. Вывод результата

**Ручная команда:** `Set-ExecutionPolicy Restricted -Force`

### 3.10. Deploy-CertificateManagerV2.ps1

Развёртывание из сетевой папки. Создаёт структуру папок, копирует файлы, 
создаёт ярлык на рабочем столе, настраивает автозапуск, через 5 секунд запускает GUI.

## 5. Конфигурационные файлы

### 5.1. all_certs_urls.txt

Список URL для скачивания. Строки, начинающиеся с `#`, игнорируются. 
Поддерживаются `.cer`, `.crl`, `.p7b`.

**Содержит ссылки на:**

INI-файл с секциями: `[AvPass]`, `[AvBign]`, `[AvCSPBel]`, `[AvCSPBign]`, `[AvReg]`.

**Поля:**
- `Name` — отображаемое имя

- `FallbackURL1`, `FallbackURL2` — резервные ссылки
- `FileName` — имя файла архива
- `InstallerName` — путь к установщику внутри архива
- `SilentArgs` — аргументы тихой установки

## 6. Политики выполнения PowerShell

| Политика | Описание |
|----------|----------|
| **Restricted** | ❌ Полное отключение — сценарии НЕ выполняются |
| **RemoteSigned** | ✅ Локальные сценарии выполняются, удалённые — только подписанные |
| **Bypass** | ✅ Всё выполняется, ничего не блокируется |
| **AllSigned** | ⚠️ Только подписанные сценарии |
| **Undefined** | ⚠️ Нет политики (используется локальная) |

**Важно:** Задача в планировщике и GUI используют `-ExecutionPolicy Bypass`, 
поэтому они работают даже при политике `Restricted`.

## 7. Обработка ошибок и логирование

**Типы логов:** 
- `import_*.log` (сертификаты)
- `avest_install_*.log` (компоненты)
- `avcmxwebp_install_*.log` (плагин)
- `autostart_*.log` (автозапуск)

**Глобальный обработчик:** 
- `Register-EngineEvent` для закрытия окна
- `trap` для перехвата ошибок

**Коды возврата:** 0 — успех, 1 — ошибка

**Типичные ошибки:**
- `NTE_BAD_KEYSET` → .NET fallback
- `already exists` → INFO, не ошибка
- `WinRAR не найден` → инструкция по установке
- `Нет интернета` → инструкция по ручной установке
- `Недостаточно прав` → автоматический запрос прав

## 10. Устранение неполадок

- **Ошибка "Не удается загрузить файл"** → Запустите `enable_scripts.ps1`
- **Окно закрывается сразу** → Запуск от администратора
- **Крякозябры вместо русского** → Сохранить скрипты в UTF-8 с BOM
- **Ошибка скачивания** → Проверить интернет и доступность сайтов
- **Не найден MngCert.exe / AvCmUt4.exe** → Установить компоненты Авест
- **Антивирус блокирует** → Добавить папку в исключения
- **Задача не создаётся** → Запустить от администратора
- **Скрипт не запускается при старте** → Проверить лог `autostart_*.log`

**Диагностика:**
```powershell
Get-Content "C:\CertificateManager V2.0\logs\import_*.log" | Select-String "ОШИБКА"
Get-Content "C:\CertificateManager V2.0\logs\import_*.log" -Tail 50
Get-ExecutionPolicy
```

## 11. Расширение и модификация

**Добавление источников сертификатов:** редактировать `all_certs_urls.txt`

**Добавление компонента Авест:**
1. Добавить секцию в `avest_urls.ini`
2. Добавить функцию `Test-NewComponent` в `Common-Functions.ps1`
3. Добавить компонент в массив `$components` в `Install-AvestComponents.ps1`
4. Добавить путь поиска в `Find-Installer`

**Изменение путей:** отредактировать переменные `$source`, `$target`, `$NetworkSource`

**Изменение расписания автозапуска:** в `Create-ScheduledTaskV2.ps1` изменить `/delay` или `/sc`
